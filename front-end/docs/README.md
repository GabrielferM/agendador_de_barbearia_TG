## Como usar e manter

Leia o [AGENTS](../AGENTS.md) e os guias relevantes à tarefa. Cada assunto tem uma fonte canônica; os demais documentos apontam para ela. Não é necessário ler toda a documentação a cada edição.

**Implementado** significa comportamento confirmado no código. **Regra para novas alterações** define a convenção a seguir. **Melhoria pendente** ainda precisa ser implementada. Ao alterar comportamento, atualize o guia, exemplos e links; não descreva uma intenção como funcionalidade disponível.

A explicação compartilhada de [AGENTS, docs e Codex](../../back-end/doc/README.md) diferencia regras, documentação e configuração. Esta organização usa Markdown versionado e não exige `.codex/config.toml` nem skills adicionais.
